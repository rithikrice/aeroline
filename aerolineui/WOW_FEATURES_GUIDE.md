## 🚨 **TROUBLESHOOTING**

### Matrix Mode not activating?
- Make sure you're in the Realtime-GeoMap page
- Try clicking the Matrix button instead of keyboard shortcut
- Press Esc to exit if stuck

### Pilot View looks weird?
- Check that a flight is selected
- Metrics should update every second
- Press "Exit Pilot View" button to return

### Inception stuck?
- Use "Zoom Out" button to go back
- Check progress dots at bottom for current level
- "Exit Inception Mode" button always available
